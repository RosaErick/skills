# Optional coordination

Use delegation only when available and authorized, and only for bounded independent work alongside useful local progress. Inspect real host tools and concurrency limits instead of assuming specialist names.

Assign ownership of shared files, give each worker the relevant context and expected artifact, and sequence dependent changes. A plan can live in the project's established location when useful; a PLAN.md check is not a prerequisite for coding.

Inspect returned diffs and evidence, integrate the changes, and verify the combined result. Continue directly when the work is too small or coupled to benefit from delegation.
