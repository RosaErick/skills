# Workflow

Como o agente conduz o trabalho: planejar, orquestrar, decidir.

- **[brainstorming](./brainstorming/SKILL.md)** — Protocolo de perguntas socráticas para requisitos vagos, além de reporte de progresso e erro.
- **[plan-writing](./plan-writing/SKILL.md)** — Planejamento estruturado: quebra de tarefas, dependências, critérios de verificação.
- **[architecture](./architecture/SKILL.md)** — Framework de decisão arquitetural: requisitos, trade-offs, ADRs.
- **[behavioral-modes](./behavioral-modes/SKILL.md)** — Modos operacionais (brainstorm, implement, debug, review, teach, ship, orchestrate).
- **[intelligent-routing](./intelligent-routing/SKILL.md)** — Seleção automática do agente/especialista certo para cada pedido.
- **[parallel-agents](./parallel-agents/SKILL.md)** — Orquestração de múltiplos agentes em paralelo por domínio.
- **[app-builder](./app-builder/SKILL.md)** — Orquestrador de construção de aplicação full-stack a partir de um pedido em linguagem natural.
