# Continuity between phases

Continue in the current session while useful context remains. There is no fixed token threshold shared by all models or hosts, and a phase boundary is not a required stop.

When a transition is necessary, preserve the objective, decisions, changed paths, test evidence and next action. Use a handoff when moving work to another person, directory or host. Use host-provided compaction when needed; do not assume slash commands exist or clear relevant history automatically.

Delegate only a bounded independent task when tools and authorization permit it. Give the worker the context it actually receives, an output contract and ownership boundaries. A context transition never changes the user's authorized scope or erases earlier decisions.
